# Framerate

This will change the amount of times that code is ran every second.

The default framerate is `60`. It can be set anywhere from `1` to `240`.

For example, if using a `repeat 60 times` block, the code run for exactly one second if the FPS are set to `60`.

:::info
This will only affect the maximum amount of FPS the project is allowed to go to. For slow devices, the FPS could be less and not match what the project sets.
:::
