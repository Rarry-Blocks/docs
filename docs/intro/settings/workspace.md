# Workspace

These options change how the block workspace behaves. They are saved in your browser, not in the project. You can find them in **Settings > Editor > Workspace**.

| Setting      | Default   | Range          | Description                                                         |
| ------------ | --------- | -------------- | ------------------------------------------------------------------- |
| Show grid    | on        |                | Shows or hides the grid lines.                                      |
| Grid spacing | `20`      | `5` to `200`   | Distance between grid lines in pixels. Also used by "Snap to grid". |
| Grid color   | `#7e7e7e` |                | Color of the grid lines.                                            |
| Default zoom | `0.9`     | `0.1` to `5`   | The zoom level the workspace starts at.                             |
| Zoom speed   | `1.2`     | `1.01` to `3`  | How much each scroll or zoom button press changes the zoom.         |
| Minimum zoom | `0.3`     | `0.05` to `5`  | How far you can zoom out.                                           |
| Maximum zoom | `3`       | `0.05` to `10` | How far you can zoom in.                                            |
